# ISO 27001 ISMS Implementation & Audit Project

This project demonstrates a simulated implementation of an Information Security Management System (ISMS) aligned with ISO/IEC 27001.

## 🔍 Project Overview
The project includes risk assessment, internal audit analysis, and control implementation based on ISO 27001 framework.

## 📂 Deliverables

### 1. Risk Assessment
- Asset identification
- Threat & vulnerability analysis
- Risk register with control mapping

### 2. Internal Audit
- Audit findings based on ISO 27001 clauses:
  - Clause 5.2 – ISMS Policy
  - Clause 6.1 – Risk Management
  - Clause 9.2 – Internal Audit
- Root cause analysis
- Corrective actions

### 3. Statement of Applicability (SoA)
- Control selection based on risk assessment
- Mapping with ISO 27001 Annex A controls
- Justification for applicability

## 🛠 Tools Used
- Microsoft Excel (Risk Register & SoA)
- Documentation aligned with ISO 27001 and ISO 19011

## 📌 Key Skills Demonstrated
- Information Security Governance (GRC)
- Risk Assessment & Risk Management
- Internal Audit Methodology
- ISO 27001 Compliance
